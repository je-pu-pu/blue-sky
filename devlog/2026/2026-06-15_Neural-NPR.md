# 2026-06-15 Neural NPR（2026-06-15 〜 07-03）

ニューラルネットで、ゲームの画面を絵画・スケッチ風に描き替える（NPR）。オフラインで確かめてから、リアルタイムでゲームに組み込んだ。

- **オフラインの検証** : ゲームの画面を書き出し（DebugScene のフレームの書き出し）、Python のツール（tools/npr_offline）でスタイルを掛けて確かめた（c6ba6e56・6d580d90）
- **目指す見た目** : 時間的に安定させるのではなく、手描きのアニメのように線が揺れる「ボイリング」。決定論的なネットでは揺れが出ないので、ノイズを入れる確率的なネットにした（4afa7325）
- **リアルタイム化** : ONNX Runtime と DirectML で推論し、ポストエフェクトとして組み込んだ（11c27955・7b8d8573）。処理解像度を下げ（6 → 16 fps）、fp16 で約 1.6 倍速くした（65145368・79a06fa2）。色を保つ処理は HLSL にした（ae42cb83）
- **整理** : NPR の流れを NeuralNprEffect クラスにまとめ、ノイズの生成に単体テストを付けた（51f582d4・134372b4）
- この組み込みのために、エンジンを 64 ビット化した（2026-06-29）
