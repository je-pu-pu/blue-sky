# devlog

開発の記録。何をしたか・なぜか・結果の数字を、あとで読み返してすぐ分かる短さで残す。

## 決まり

- 年ごとのフォルダ（`2026/` など）に、**まとまった出来事ごとに 1 ファイル**を置く。毎日の作業ではなく、検証や作り直しなどの区切りで書く。小さなことは、その時期の出来事のファイルに書き足す
- ファイル名は `YYYY-MM-DD_題名.md`（スペースを入れない。日付は始めた日）
- 画像はその年の `images/` に `YYYY-MM-DD_短い名前.png` で置く
- 1 ファイルは画面 1〜2 枚で読める長さにする。詳しい設計や経緯は `doc/` に書き、ここからはリンクするだけにする
- 書いたら、下の一覧に 1 行足す（新しい順）
