# blue-sky 動詞とゲームシステム

ゲームのコア動詞を、どのゲームシステムに対応させるかの設計メモ。
関連: [テーマ.md](テーマ.md) / [ストーリー構想.md](ストーリー構想.md) / [blue-sky 面白さの原則.md](blue-sky%20面白さの原則.md)

## コア動詞

このゲームの動詞は5つ:

**飛ぶ / 隠れる / 逃げる / 隙を突く / 探索する**

敵は**ロボット**。人間（プレイヤー）は地上では弱く、機械に対して正面からは不利。
人間側の唯一の優位が「飛ぶ＝空（縦）への逃避と憧れ」であり、これがテーマ
（人間 vs AI、空への憧れ、存在の肯定）とメカニクスを一致させる軸になる。

---

## 1. 3層構造

5動詞は役割で3層に分かれる。

```
探索する            ← マクロ層: 世界を巡り、理解する（ゲーム全体の構造 / Immersive Sim）
飛ぶ                ← 接続層: 縦軸の移動。逃走と探索を“上”でつなぐ、本作固有の武器
隠れる / 逃げる / 隙を突く  ← ミクロ層: ロボットとの遭遇で使う基本ステルス（Thief / MGS / Shadow Tactics 系）
```

| 動詞 | 層 | システム |
|---|---|---|
| 探索する | マクロ | 飛んで街を俯瞰→ルート/敵/資源を読む→家屋に降りて内部探索。世界が語る。痕跡が残る |
| 飛ぶ | 接続/縦 | 消費資源型。手段ごとに別プロファイル。高さ＝自由を“買う” |
| 逃げる | ミクロ | 追跡AIから離脱。水平（角・距離）＋**垂直（上へ＝歩行ロボは追えない）**＝固有の逃げ |
| 隠れる | ミクロ | 光と影・遮蔽・視線切り＋センサー錐の回避。屋上/庇など縦と接続 |
| 隙を突く | ミクロ・コア | 見ていない隙に移動／背後・上から無力化（電源カット・センサー破壊）。正面戦闘は不利。1遭遇に複数解法 |

「隙を突く」が Immersive Sim の核＝**世界を読んで系統的に解く**動詞。

---

## 2. 縦軸 ＝ 自由の勾配（テーマとの一致）

```
高い ── 自由・安全・選択肢が多い（空 ＝ 憧れ・開放）
  ↑      ……でも飛行は資源で有限。ずっとは居られない
  │      ロケット花火 / 風船 / 傘（一時的な飛行手段）
  ↓
地上 ── 危険・敵だらけ・不自由（ロボットの支配領域）
```

- **飛ぶ＝有限資源で“一時的な自由”を買う**。資源が尽きれば必ず地上（危険）へ落ちる。
- これは「**地面と空のあいだ**＝どちらにも属さない人間の条件」を経済システムで強制する。
- エンディングの「自発的に飛ぶのをやめて地に立つ」＝資源を使わない選択、とメカニクスで表現できる。
- 高ければ高いほど自由。ただし完全な楽園ではない（対空タイプの存在。後述）。

## 3. 消費アイテム（飛行＋ステルス道具）

すべて消費資源型。世界の拾い物・敵ドロップで入手（→ 7章）。

| アイテム | 機能 | 役割 |
|---|---|---|
| 風船 | 少し宙に浮く | **上がる** |
| 傘 | 高所から落ちても死なない | **降りる**（安全に地上/家屋へ） |
| ロケット花火 | 敵の注意を引き寄せる（陽動） | **引く**（隙を作る・攻） |
| 煙玉 | 敵の視界を奪う（煙幕） | **消す**（隠れる・逃げる・守） |
| フリーズ（仮） | 敵の動きを一瞬止める | **止める**（時間を作る）※強力なので特に希少・高コスト |

「上がる／降りる／引く／消す／止める」で隙の作り方が揃う。冗長がなく、組み合わせで解法が生まれる。

---

## 4. 敵：システム的AI

敵の動きは**台本（スクリプト）で決め打ちしない**。一貫した**ルール**で動かし（systemic AI）、
プレイヤーが読んで利用できる創発的状況を生む。「システムが世界を支配している」原則そのもの。

各ロボットが持つルール:
- **知覚**: 視界錐（可視化する）＋ 聴覚
- **警戒の状態機械**: 無警戒 → 不審 → 捜索 → 警報
- **刺激への反応**: 花火の音→そっちを調べる / 停止したロボを発見→警報 / 煙で視界を失う 等
- 追跡: navmesh（Recast & Detour）＋ オフメッシュリンク ＋ 警戒状態機械

### 知覚モデル（上を見るか問題）
折衷案を採用:
- **基本約束事: 地上の歩行ロボットは上を見ない**（＝垂直は基本的に安全。テーマ「高いほど自由」を保証し、プレイヤーが安心して縦を使える固有色になる）
- **例外として“対空タイプ”を少数配置**: 飛行ドローン／上向きサーチライト／上方センサー。「空にも少しだけ脅威」。

→「上＝基本は自由、でも油断はできない」。分かりやすさ＋タクティカルな変化＋テーマを両立。

### 無力化
- 正面戦闘は不利（高致死）。背後・上から、電源カット、センサー破壊で無力化。
- 停止させたロボットは別のロボットが発見すると警報→見つからない所に隠せる（死体隠し）。

## 5. 環境ギミックと要素の相互作用（emergent）

道具だけでなく**環境そのもの**を使って解く。Immersive Sim の華＝要素の相互作用。

例:
- **水 ＋ 電気**: 地面に水を撒く → 通電させて感電 → その範囲の敵の動きを止める。
- （拡張余地）水＋寒さ＝凍結で足場 / 火＋可燃物＝延焼で陽動 / 油＝滑走 など、一貫したルールで相互作用させる。

原則: 個々の要素に**ルール**を与え、組み合わせはプレイヤーが発見する（設計者は解法を1つに固定しない）。

## 6. 失敗モデル（死亡・警報）

「死んだらチェックポイントから自動でやり直し」は**やらない**。完全リセットもしない。
失敗は「やり直し」ではなく「**世界に残る結果**」（面白さの原則: ミスは世界に刻まれる／引き返せない）。

- **死亡/捕捉 → そのステージの最初に戻る**（途中オートセーブ再開はしない。Shadow Tactics の思想）
- **戻った世界は変化している = 敵が増える**（blue-sky 独自のひねり）
  - 増加には**上限あり**（無限増加はバランス崩壊）
  - 増えた敵は**基本一切戻らない**（ハード）
  - **難易度オプション**で「居座る／沈静化する」を切替可能
- 死亡時、**積み上げた“そのステージの強さ”もリセット**（→ 9章）。死は重い。
- **正面攻撃でダメージを負う**（HP あり）。低HP・高致死で「正面不利・ステルス必須」を担保。

### 最重要バランス則
> 敵増加の上限は「**強さゼロからでもクリア可能**」な範囲に収める。
> 増加は“難しくする”が“不可能にはしない”。これで「失敗は痛いが詰まない（死のスパイラル回避）」。

## 7. 資源2系統

| 系統 | 入手 | 用途 | プレイスタイル |
|---|---|---|---|
| 強化資源 | 敵ドロップ | そのステージで強くなる | 危険な掃討（リスク→リターン） |
| 消費アイテム | 世界の拾い物 | 風船・煙玉等の補給 | 安全な探索 |

「危険だが強くなる／安全だが弱いまま」のリスク・リターン。
ghost プレイ（避ける）も掃討プレイ（削る）も成立＝「正解ルートは複数」。

## 8. 無双（パワーカーブ）＝ 一部ステージ限定・per-stage

- 敵を**コツコツ（巧いステルス撃破で）**削る → ドロップで強化 → 最後は無双できる。
- ただし:
  - **一部の特別ステージのみ**（全ステージ標準にしない）。希少だから快感が映える。多くのステージは弱いままでステルス必須＝固有色を維持。
  - **強さはそのステージ限り（per-stage、次に持ち越さない）**。
- 強くなる過程も**正面戦闘ではなくリスクのあるステルス撃破**（電源カット・背後/上から・センサー破壊）。

### テーマとの結合（重要）
「per-stage で消える」は、ストーリーの **「力で掴んだ花は枯れる／奪ったものは自分のものにならない／力で得たものは残らない」** をメカニクスで体現する。
→ 無双は“バグ”ではなく、W1（力の快感 → 虚しさ）の体験装置。全編で力押しできるとテーマ C（達成ではなく肯定）と戦うため、希少に留める。

## 9. ワールド別の動詞の重み（心理アークと一致）

動詞セットは固定でなく、ワールドごとに重み・権能が変わる。解禁の順序がそのまま心理アーク
（憧れ → 挫折 → もがき → 気づき → 肯定）。ステージ進行で“できること”を増やすチュートリアル構造とも一致。

| ワールド | 状態 | 動詞の重み |
|---|---|---|
| W0 | 浮遊・脆い・無力 | 飛ぶ／隠れる／逃げる／すり抜ける（倒せない）。飛行が主武器 |
| W1 | 重い・破壊的 | 「隙を突く」が破壊・無力化の権能を得る。無双ステージ多め。飛行は減る |
| W2 | 地上・歩行 | 飛行を手放す。ステルス/探索が静かな文脈に |

## 10. 設計原則との対応（面白さの原則 / Immersive Sim）

- 世界はあなたを助けない … 高致死・親切なヒントなし
- 納得できる成功 … 複数解法、自分の判断で解く
- 物語を世界から読み取る … 痕跡・配置・結果が語る（一人称・無言）
- システムが世界を支配 … systemic AI ＋ 要素の相互作用
- 判断を間違えたら本当にまずい … 失敗が世界に刻まれる（敵増加・警戒持続）
- 正解ルートが複数 … ghost / 掃討 / 飛び越え / 環境利用
- 観察と判断が結果を決める … 視界錐を読み、隙を突く
