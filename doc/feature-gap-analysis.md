# blue-sky フィーチャーギャップ分析

一般的なゲームが備える機能を基準に、blue-sky の現状と不足点を整理する。

---

## 凡例

| 記号 | 意味 |
|------|------|
| ✅ | 実装済み |
| ⚠️ | 部分的に実装 / 改善の余地あり |
| ❌ | 未実装 |

---

## 1. コアゲームプレイ

| 機能 | 状態 | 備考 |
|------|------|------|
| プレイヤー操作 (移動・ジャンプ・アクション) | ✅ | 歩行、走行、ジャンプ、ロケット飛行、傘降下、石投げなど豊富 |
| 敵 AI | ✅ | Robot: 巡回、注意、追跡、停止など複数モード |
| NPC | ⚠️ | Girl が存在するが、会話・クエスト連動なし |
| コレクティブル | ✅ | バルーン、メダル、アイテム各種 |
| ステージクリア / ゴール | ✅ | Goal オブジェクト + ステージ進行管理 |
| コンボシステム | ✅ | バルーン連続取得によるシーケンスカウント |
| ボス戦 | ❌ | ボスキャラクター・ボス専用ステージが見当たらない |
| 難易度設定 | ❌ | Easy / Normal / Hard 等の選択肢なし |
| クエスト / ミッション | ❌ | 目標追跡・クエストログなし |
| タイマー / タイムアタック | ⚠️ | タイマー基盤はあるが、ゲームモードとしてのタイムアタックはない |

## 優先度別まとめ

### 高優先度 (ゲーム体験に直結)

1. **ポーズメニュー** — ゲームプレイ中に一時停止・設定変更・リタイアができない
2. **オプション画面 (GUI)** — 音量、操作、グラフィックスを GUI で変更できない
3. **チュートリアル** — 初回プレイヤーが操作を学ぶ手段がない
4. **HUD の充実** — HP・アイテム・コンボ数などの画面表示が不十分
5. **ローディング画面** — ステージ遷移中にフリーズしたように見える
6. **ダメージフィードバック** — 被弾時の視覚・カメラ演出がない

### 中優先度 (ゲームの深みと完成度)

7. **難易度設定** — 幅広いプレイヤー層への対応
8. **オートセーブ / チェックポイント** — 進行ロスの防止
9. **カメラシェイク** — 衝撃・着地等の迫力ある演出
10. **環境音 (アンビエント)** — 空を飛ぶゲームなら風音等は必須級
11. **音量調整 UI** — スライダーでの直感的な音量操作
12. **キーリバインド UI** — ゲーム内でのキー設定変更
13. **NPC 対話システム** — Girl との会話・ストーリー連携
14. **パーティクルバリエーション** — 火・煙・風・水しぶき等の種類追加
15. **非同期アセット読み込み** — ローディング時間の体感短縮

### 低優先度 (あると嬉しい)

16. **天候システム** — 雨・雪・霧で空の印象を変える
17. **実績システム** — プレイのモチベーション向上
18. **ミニマップ** — 空中探索時の方向感覚の補助
19. **V-Sync オプション** — ティアリング防止
20. **スクリーンショット / フォトモード** — 空を飛ぶ美しいシーンの共有
21. **ゲームパッド振動** — アクションへの触覚フィードバック
22. **ローカライゼーション** — 日本語以外の言語対応
23. **ボス戦** — ステージの区切りとなる大きなイベント
24. **アクセシビリティ** — 色覚サポート、字幕カスタマイズ等
25. **リプレイ / タイムアタック** — やりこみ要素の追加
