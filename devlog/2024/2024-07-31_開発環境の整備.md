# 2024-07-31 開発環境の整備（2024-07-31 〜 08-17）

作りながら確かめやすくするための道具をそろえた。

- **シェーダーのホットリロード** : ゲームの実行中に .hlsl を書き換えると、ゲームに戻ったときに自動で読み直す（a9425570・34808877）
- **imgui 1.91.0 とコンソール** : imgui のソースをプロジェクトに入れて管理。スクリプトの入力とエラーの表示を、F1 で開くコンソールの窓にした。シーン一覧の窓も作った（d8b3dca3・03c1cd88）
- **数学ライブラリ** : Transform・Quaternion を DirectXMath で作り直し、`core::math` の名前空間を整理した（0dffdb01）
- **カメラの操作** : TransformControlSystem でマウスによる視線の移動（上は常にワールドの上。pitch は ±90° まで）（98b29a68・d59c66ee）
- **そのほか** : Bullet を 3.25 に更新。UI のフォントを Rounded M+ に。テストが Visual Studio のテストエクスプローラーに出るようにした。Wintab32.dll が無いと止まる問題を直した
