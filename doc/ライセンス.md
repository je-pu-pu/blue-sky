# ライセンス（使っているライブラリと素材の一覧）

作成: 2026-11-11（ブランチ feature/ui-library）

ゲームを配布するときに、第三者のライブラリ・素材のライセンスが求める著作権表示と許諾の文を同梱するための、開発用の一覧。

- **配布物に同梱するファイル**: リポジトリの直下の `THIRD_PARTY_NOTICES.txt`（配布物に入るものだけを載せた。条文は原文のまま）
- **この文書**: どれが配布物に入るか・入らないか、ライセンスの種類、配布のときにすること、要確認の点

`THIRD_PARTY_NOTICES.txt` を .md ではなく .txt にした理由:

- 配布物にそのまま入れて、利用者がメモ帳で読める（Markdown の表示環境を前提にしない）
- 条文を原文のまま写すので、Markdown として解釈される（`*`・`_`・字下げ・改行の詰め）と原文が崩れる

ファイルは手元の原文（LICENSE のファイル・ヘッダの注記・FBX SDK の License.rtf）から機械的に写して作った。写し元は各項目の「写した元」に書いた。

## 4. 特に注意が要るもの

### 4.1 Autodesk FBX SDK（独自のライセンス）

License.rtf（2020.3.9）で確かめたこと:

- **1.1.5**: 次の文を、(i) エンドユーザー向けのライセンス・利用規約 か (ii) About ボックス・同様の表示の画面 の著作権の欄に置き、**さらに** (a) オンラインの文書 か (b) 著作権の情報を載せた文書 にも置くこと。THIRD_PARTY_NOTICES.txt に載せたのは (b) にあたる。**(i) か (ii) も要る**（ゲームの利用規約か、クレジット・About の画面）。
  > "This software contains Autodesk® FBX® code developed by Autodesk, Inc. Copyright 2019 Autodesk, Inc. All rights, reserved. Such code is provided "as is" and Autodesk, Inc. disclaims ..."（全文は THIRD_PARTY_NOTICES.txt）
- **1.1.4**: ソフトウェアに含まれる著作権の表示を、作ったソフトウェアのすべての写しに付ける。
- **1.1.3**: 作ったソフトウェアは、FBX SDK の部分を「as is」（保証なし）として再許諾する条件で配布してよい。
- 10.2（Media & Entertainment のサンプル・再頒布部品の例外）は、FBX SDK のサンプルのコードを使うときの話。サンプルを写していなければ当たらないはず（要確認）。

選択肢: 配布前にモデルを独自の形式（例: 変換済みのバイナリ）にしておき、ゲームの exe から FBX SDK を外せば、この義務と libxml2・FBX 側の zlib が配布物から消える（fbx-converter だけが FBX SDK を使う形）。

### 4.2 FreeType（FTL の表示義務）

FTL は、バイナリで配るとき「FreeType Team の成果に一部基づく」旨を配布物の文書に示すことが義務（FTL.TXT の「2. Redistribution」）。文言は FTL.TXT の推奨の文:

> Portions of this software are copyright © 2025 The FreeType Project (https://freetype.org). All rights reserved.

`<year>` は使う版の年にする決まりで、2.14.1 の freetype.h の著作権が 1996-2025 なので 2025 にした。THIRD_PARTY_NOTICES.txt に載せた。マニュアルやクレジットにも載せるとなお良い。

FreeType は GPLv2 との二者択一だが、**FTL を選ぶ**（GPL の義務を負わない）。BDF・PCF のドライバ（`freetype.vcxproj` でビルドしている）は X 系の許諾で、条文を THIRD_PARTY_NOTICES.txt に載せた。BDF・PCF・Type1・CID・PFR・Type42・WinFonts などのドライバは TTF だけ読むなら要らないので、外せば載せる条文が減る（任意）。

### 4.3 ONNX Runtime・DirectML（DLL の再配布）

- ONNX Runtime は MIT（ヘッダで確かめた）。ただし配布元のパッケージには **ThirdPartyNotices.txt** があり（手元に無い。要確認）、DLL に入っている第三者のコードの表示がそこにある。**DLL と一緒に ThirdPartyNotices.txt を同梱する**のが無難。
- DirectML.dll は NuGet の `Microsoft.AI.DirectML` の再頒布部品のはず（要確認）。ライセンスは Microsoft の独自のもので、**再配布の条件をパッケージの LICENSE.txt で確かめる**（手元にパッケージが無い。lib/x64 に DLL だけ置いてある）。OS にも DirectML.dll が入っているはずだが、onnxruntime が要る版は同梱の 1.15.4 のはず（どちらも要確認）。
- `onnxruntime_providers_shared.dll` も onnxruntime の配布物の一部（MIT）。

### 4.4 Oculus SDK

今は無効（2 章・3 章）。VR を有効にして LibOVR をリンクするときは、Oculus SDK License の再配布・表示の条件を確かめ、THIRD_PARTY_NOTICES.txt に足す。手元の `lib/include/OVR_CAPI.h` には「Copyright (c) Facebook Technologies, LLC and its affiliates. All rights reserved.」だけがあり、ライセンスの文は無い。

### 4.5 GPL・LGPL が混ざっていないか

- 配布物に入るライブラリに **GPL・LGPL のものは無い**（2 章の表）。FreeType は GPLv2 との二者択一で FTL を選ぶ。
- portable-file-dialogs は WTFPL（制限なし）。
- Python のツールの依存は配布しないので関係しない。
- 素材は下の 4.6。

## 5. 配布のときにすること

1. `THIRD_PARTY_NOTICES.txt` を配布物（exe と同じフォルダ）に入れる。
2. `THIRD_PARTY_NOTICES.txt` の「【要確認】」をすべて片付ける（今 19 か所）。片付けたら各項目の「写した元」の注意書きも消す:
   - 配布元から原文を取って全文を写す: libogg・libvorbis の COPYING、Boost の LICENSE_1_0.txt、libxml2 の Copyright、ONNX Runtime の LICENSE（照合）と ThirdPartyNotices.txt、Dear ImGui の LICENSE.txt（照合）、libremidi の LICENSE、DirectML の LICENSE.txt
   - 版を確かめる: PortAudio・libogg・libvorbis・portable-file-dialogs・WICTextureLoader
   - WICTextureLoader のライセンス（MS-PL か MIT）を確かめる
3. FBX SDK の表示の文を、利用規約か About・クレジットの画面にも入れる（4.1）。または FBX SDK を exe から外す。
4. ONNX Runtime の ThirdPartyNotices.txt を DLL と一緒に入れる。DirectML.dll の再配布の条件を確かめる（4.3）。
5. 素材を絞る: `takarajima.mid`・`SGM-V2.01.sf2`・`uzura.ttf`・`ground-gemini*.png` を配布物に入れない。`FluidR3_GM2-2.SF2` はライセンスを確かめるまで入れない（4.6）。
6. Rounded M+ のライセンスを確かめ、要るなら表示を足す。
7. Release の exe で `dumpbin /dependents` を取り、配る DLL が onnxruntime.dll（＋ onnxruntime_providers_shared.dll・DirectML.dll）だけであることを確かめる。
8. ライブラリを足した・替えたときは、この文書の 2 章・3 章と THIRD_PARTY_NOTICES.txt を直す。
