# 2026-02-14 オプション画面と文字の描画（2026-02-14 〜 02-25）

オプション画面を作り、そのために 2D の描画・UI・文字の描画を作り直した。

- **オプション画面** : 2D 描画の基盤（UIRenderer）とメニューを足し、設定の項目・バー表示・保存を作った。矢印キー・Enter・マウスで操作できる（35f5ca46・12ca02e3・10bcdab4・383835fb）
- **解像度** : UI を解像度に依存しない仮想の座標にし、オプション画面で解像度を変えられるようにした（75931c16・b5234170）
- **MSDF の文字** : FreeType 2.14.1 と msdfgen 1.13 で、どの大きさでもくっきりした文字を描く。DirectWrite と Direct3D 10.1 をやめ、文字の描画を MSDF に統一した（28988376・9c95b62f・245f83b8）
- **UI の部品** : ボタン・スライダー・選択の部品と入れ物を作り、core 層に置いた（5fcd7d35・ecefcf3a）
- **層の整理** : core 層から blue_sky 層への依存を解消した（c36ecc6f）
- UI ライブラリは 2026-11 の整備で作り直し、オプション画面を組める形にした（doc/UIライブラリ設計.md）
