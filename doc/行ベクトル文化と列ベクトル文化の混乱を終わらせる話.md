# 行ベクトル文化と列ベクトル文化の混乱を終わらせる話

> 「transpose したら直った」
>
> 「row_major にしたら動いた」
>
> 「でも、なぜか説明できない」

──そんな経験、ありませんか？

この記事は **HLSL / DirectX / 数学の資料がごちゃ混ぜになって脳が破壊された人向け** に、

- 行ベクトル文化
- 列ベクトル文化
- row_major / column_major

この3つを**完全に切り分けて整理**します。

---

## 先に結論（これだけ覚えて帰って）

- **行ベクトル文化 / 列ベクトル文化**は「計算の流儀」
- **row_major / column_major**は「メモリ上の並び方」
- ただし **実務ではこの2つは密接に結びついている**
- 「動くけど意味的におかしいコード」は普通に存在する（そして一番危険）

---

## 行ベクトル文化とは何か

ベクトルを **行** として扱います。

```
pos' = pos * World * View * Projection
```

- ベクトルは左から掛ける
- 行列の合成は **左 → 右** に読む
- DirectXMath / D3DX 系はこの文化

### 特徴

- C/C++ の配列感覚に合う
- コードとして直感的
- 数学の教科書とはだいたい逆

---

## 列ベクトル文化とは何か

ベクトルを **列** として扱います。

```
pos' = Projection * View * World * pos
```

- ベクトルは右から掛ける
- 行列の合成は **右 → 左** に読む
- 数学・線形代数・OpenGL・GLSL はほぼこれ

### 特徴

- 学術的・理論的に自然
- 教科書・論文はほぼこれ
- 実装時に混乱しやすい

---

## row_major / column_major とは何か

これは **文化ではありません**。

> **メモリ上で、どう並んでいるか** だけの話です。

```cpp
row_major    -> m[row][col]
column_major -> m[col][row]
```

HLSL では、

```hlsl
row_major float4x4 M;
column_major float4x4 M;
```

のように指定できます。

---

## ここで最大の勘違いが起きる

> row_major / column_major は
> 行ベクトル文化 / 列ベクトル文化と
> **完全に独立している**

──という説明、よく見ます。

### 半分正しくて、半分ウソです

**理論上は独立**ですが、
**実務ではほぼセット**で使われます。

| 計算文化 | よく使われる指定 |
|---|---|
| 行ベクトル文化 | row_major |
| 列ベクトル文化 | column_major |

理由は単純で、

> その方が **人間の理解とコードの意味が一致する** から。

---

## 「意味的におかしいけど動く」パターン

### 例

- CPU：行ベクトル文化で行列を作る
- CPU：transpose して GPU に送る
- HLSL：column_major で受け取る
- HLSL：行ベクトル文化で計算する

```hlsl
return mul( mul( mul( pos, W ), V ), P );
```

### 結果

✔ 動く
✔ 見た目も正しい
❌ **コードの意味は破壊されている**

なぜなら、

> 「column_major ですよ」と言っておきながら、
> 行ベクトル文化として扱っている

からです。

---

## なぜそれでも動くのか

理由はシンプルです。

- CPU 側で transpose
- GPU 側で row/column の指定を逆に読む

👉 **結果としてメモリ配置が元に戻る**

つまり、

> 「偶然つじつまが合っている」

状態です。

---

## 何が危険なのか

- 数学資料を読んだ瞬間に破綻
- 別の人がコードを触ると事故る
- 行列合成順を変えた途端に崩壊
- 法線変換・逆転置で地獄を見る

👉 **長期的に必ず破綻します**

---

## 安全な指針（おすすめ）

### どちらかに統一しよう

#### パターンA（DirectX王道）

- CPU：行ベクトル文化
- CPU：transpose しない
- HLSL：row_major
- HLSL：行ベクトル文化

#### パターンB（数学・GLSL寄り）

- CPU：列ベクトル文化
- CPU：transpose する
- HLSL：column_major
- HLSL：列ベクトル文化

**混ぜない。絶対。**

---

## なぜ数学の教科書は列ベクトル文化なのか

- 線形写像 `f(x) = Ax`
- 合成 `A(Bx)` が自然
- 抽象代数・テンソルとの相性

👉 **人類の数学は列ベクトルで進化した**

ゲーム業界だけが少し異端です。

---
