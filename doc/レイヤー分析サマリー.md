# blue_sky / core レイヤー分析サマリー

## 結論: 今回はリファクタリングしない

分析結果を記録し、将来のリファクタリングの参考とする。

## blue_sky にあるが core にあるべきもの

- draw_text / get_sprite / get_screen_width/height（2D 描画 API）
- UI フレームワーク（Widget, Button, Slider, SelectBox, Renderer）
- ConstantBuffers の一部（ObjectCB, BoneCB）
- 基本シェーダ（FlatShader, LitShader, PointSpriteShader）
- Model, Mesh, Line の基本クラス
- Fader, ObjFileLoader, FbxFileLoader

## core にあるが blue_sky にあるべきもの

- FpsPlayerComponent / FpsPlayerControlSystem
- BalloonComponent / BalloonSystem
- TransformControlComponent / TransformControlSystem

3. `ParticleRenderSystem` -> `blue_sky/ConstantBuffers.h` + `PointSpriteShader.h`

## CB アーキテクチャの方針

ConstantBuffer のテンプレート基盤（`ConstantBuffer<Slot>`, `ConstantBufferTyped`, `ConstantBufferWithData`）は core 層にあり、ゲーム固有の CB は blue_sky 層で構造体を定義してテンプレートに渡すだけで追加できる。

リファクタリング時の方針:
- **core が必要とする CB** -> core に移動（ObjectCB, BoneCB）
- **ゲーム固有の CB** -> blue_sky に残す（FrameDrawingCB, GameCB 等）
- **新しいゲーム固有 CB** -> blue_sky で自由に追加可能（レジスタ番号の衝突に注意）
